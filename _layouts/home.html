Step 2

安装 CLI，连接百炼

安装 ModelStudio CLI 并配置百炼 API Key，把模型、搜索、多模态、应用和部署能力交给 Agent 调用。

运行一个 Skill

查看精选 Skills →
Recommended combination

Qwen Code + ModelStudio CLI
