## 怎么参赛

1. **动手做作品**：用阿里云百炼 CLI、OpenWork 或 Agent Skills，围绕真实场景做出一个能跑起来的 AI 作品——工具、Agent、工作流、Demo 都可以。
2. **一键提交**：点击上方「提交参赛作品」，按模板填写项目名称、团队/作者、你做了什么、用到的能力、效果展示和项目链接即可。作品会以带 `外滩大会2026` 标签的 Issue 形式登记。
3. **收录与展示**：符合要求的作品会被收录进[社区案例库](/showcase/)，并在外滩大会 2026 相关渠道获得展示机会。

## 提交前建议准备

- **一句话说清做了什么**：让人一眼看懂作品解决了什么问题。
- **效果展示**：截图、录屏或在线体验链接，至少一项，越直观越好。
- **可复现的线索**：用到的百炼能力/模型、Skill 名称、关键命令或仓库地址，方便他人上手。

## 需要的工具

- **阿里云百炼 CLI**：一行命令调用文生图、视频、语音、RAG、搜索等全模态能力，为 AI Agent 而生。[了解 CLI →](https://github.com/modelstudioai/cli)
- **OpenWork**：开源桌面 AI Agent 工作空间，内置百炼 CLI，安装即用。[GitHub →](https://github.com/modelstudioai/openwork)
- **Agent Skills**：可复用的 AI 能力模块，一句话驱动完整工作流。[精选列表 →](/skills/)

还没有 API Key？先[注册阿里云百炼并创建 Key](https://bailian.console.aliyun.com/cn-beijing/?source_channel=key_github&tab=app#/api-key)，新用户默认有免费调用额度。
